# North Georgia Awning LLC - Website
Custom website built by ValleyForge Digital

## Development
```bash
cd src
npm install
npm run dev
```

## Structure
- `/src` → all code (Astro components, pages, styles)
- `/public` → static assets (images, favicon, fonts)
