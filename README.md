## Development
```bash
cd src
npm install
npm run dev
```

## Structure
- `/src` → all code (Astro components, pages, styles)
- `/public` → static assets (images, favicon, fonts)
- `/assets/client-provided` → raw files from Sarah
- `/assets/final-exports` → optimized images you create
